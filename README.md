# OxyCare – version simple

Deuxième proposition de site pour OxyCare (anciennement Oxygène Excellence Assistance), Agdal, Rabat.
Version épurée, sur 4 pages : Accueil, Services, Offre MRE, Contact.

Site en ligne : https://douniaelabbassi-dounia.github.io/oxycare-v2/

- Site statique (HTML, CSS, JavaScript), sans dépendances
- Bilingue français / arabe
- Coordonnées modifiables dans le bloc `CONFIG` de `js/app.js`
